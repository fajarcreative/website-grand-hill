# Perumahan Grand Hill Residence Malang

Landing page resmi untuk **Grand Hill Residence Malang** — Hunian modern asri di perbukitan Wonokoyo, Kedungkandang, Kota Malang.

## Fitur Utama
- **Katalog Tipe Rumah**: Tipe 36/60, Tipe 45/72, dan Tipe 60/84 (2 Lantai).
- **Kalkulator Simulasi KPR**: Simulasi angsuran bulanan, DP, dan tenor KPR secara langsung.
- **Social Proof**: Ulasan terverifikasi Google Maps rating 4.8★ (112+ ulasan).
- **Booking & Konsultasi**: Integrasi form survei lokasi dan klaim promo langsung ke WhatsApp marketing.
- **Akses & Fasilitas**: Info legalitas SHM/IMB, one gate system, dan lokasi strategis.

## Tampilan Desain
- Framework: Tailwind CSS
- Tipografi: Newsreader & Plus Jakarta Sans
- Icon: Google Material Symbols
